# 模型验证报告（负结果）

结论先说：**在 2010–2026 的样本上，没有任何统计模型能稳定超过 AUC 0.60；训练出来的模型不比现有规则更好。因此不部署机器学习模型。**

本目录保留了全部可复现脚本和数字，供日后数据变多时重跑。

---

## 1. 数据与标签

| 项 | 内容 |
|---|---|
| 样本 | 4003 个交易日（2010-12-20 ~ 2026-08-07） |
| 主序列 | USD/CNY 日收盘（ECB / frankfurter） |
| 辅助 | 美元指数（六货币套算） |
| 标签 A | 未来 60 个交易日涨幅 ≥ 1%（跑赢人民币定存），基率 **26.1%** |
| 标签 B | 未来 60 个交易日涨幅 > 0（纯方向），基率 **39.7%** |

## 2. 试过的模型

| 模型 | 说明 |
|---|---|
| 3 状态高斯 HMM + 状态内逻辑回归 | 主方案：先识别制度状态，再在状态内拟合 |
| 逻辑回归（3 / 6 特征，强 L2） | 常规做法对照 |
| 单特征（回撤 / 波动率，单调） | 找最强单因子 |
| 现有规则打分 | 基线 |

验证：**Purged walk-forward，5 折，折间 embargo 60 天**，训练权重 1/H 抵消重叠窗口。

## 3. 结果

### 标签 A（涨 ≥1%）

| 模型 | 平均 AUC | 逐折 |
|---|---|---|
| 规则分（4 信号） | 0.508 | 0.58 / 0.68 / 0.56 / 0.48 / 0.24 |
| 单特征 回撤（取反） | 0.557 | 0.57 / 0.56 / 0.43 / 0.60 / 0.61 |
| 单特征 波动率（取反） | 0.460 | 0.76 / 0.47 / 0.50 / 0.40 / 0.17 |
| LR 3 特征 dd/vol/rsi | **0.557** | 0.62 / 0.43 / 0.63 / 0.59 / 0.52 |
| LR 3 特征 dd/vol/div | 0.534 | 0.57 / 0.40 / 0.57 / 0.41 / 0.72 |
| LR 6 特征 | 0.549 | 0.49 / 0.41 / 0.67 / 0.61 / 0.57 |
| **HMM + 状态内 LR** | **0.399** | 0.54 / 0.56 / 0.17 / 0.53 / 0.20 |

### 标签 B（涨 >0）

| 模型 | 平均 AUC | 逐折 |
|---|---|---|
| 规则分（4 信号） | **0.574** | 0.57 / 0.68 / 0.62 / 0.49 / 0.51 |
| 单特征 回撤（取反） | 0.521 | 0.54 / 0.53 / 0.54 / 0.58 / 0.41 |
| LR 3 特征 dd/vol/rsi | 0.565 | 0.55 / 0.46 / 0.57 / 0.58 / 0.67 |
| LR 6 特征 | 0.561 | 0.52 / 0.44 / 0.59 / 0.56 / 0.69 |

### 预测期限敏感性（标签 B）

| 期限 | 基率 | 规则 AUC | LR AUC |
|---|---|---|---|
| 20 日 | 43.1% | 0.543 | 0.564 |
| 60 日 | 39.7% | 0.558 | 0.529 |
| 120 日 | 41.3% | 0.563 | 0.498 |
| **250 日** | 51.4% | **0.339** | 0.314 |

注意最后一行：**一年期限上，这些「底部信号」是反向的**（AUC 0.34，远低于随机的 0.5）。亮了之后一年，美元平均更弱。这印证了「有序升值会持续」而不是「见底反弹」。

## 4. 为什么失败

1. **状态非平稳**：同一特征在 2013–2015 的 AUC 是 0.87，在 2019–2022 只有 0.48。制度换了，系数的含义也换了。
2. **有效样本极小**：3550 天 ÷ 60 天重叠窗口 ≈ 59 个独立观测。任何 5 参数以上的模型都在拟合噪音。HMM + 状态内 LR 参数超过 30 个，直接崩到 0.399——比随机还差。
3. **标签基率漂移**：逐折基率从 10% 到 49%，模型学到的是「那个时期」的偏度。

## 5. 但有价值的东西：经验频率表

不拟合参数、直接用历史频率，反而是最稳的「模型」：

| 规则分 | 样本 | P(60日涨>0) | P(60日涨≥1%) | 平均涨幅 |
|---|---|---|---|---|
| 0 | 1279 | **24.3%** | 16.7% | **−0.55%** |
| 1 | 2536 | 49.1% | 32.3% | +0.33% |
| 2 | 186 | **58.1%** | **41.9%** | +0.37% |
| 3 | 2 | 样本不足 | | |
| 4 | 0 | 从未出现 | | |

按回撤分档（更细）：

| 回撤区间 | 样本 | P(涨>0) | 平均涨幅 |
|---|---|---|---|
| 0 ~ −6% | 2900 | 42% | −0.06% |
| −6% ~ −8% | 535 | **30%** | −0.19% |
| −8% ~ −10% | 292 | 43% | +0.73% |
| **< −10%** | 188 | **60%** | **+1.62%** |

**关键发现：−6%~−8% 是最差区间**（P(涨)=30%），比浅回撤还差。说明「跌了一点」不等于「跌到位」，只有跌破 −10% 才有统计意义。

## 6. 建议

1. **不部署 ML 模型**（未达 AUC 0.60 门槛，且 HMM 版本 0.399 比随机还差）；
2. 把「规则分 → 经验概率」做成查表输出，明确标注样本量，避免黑箱；
3. 回撤阈值从 −8.5% 改成 **−10%**（浅回撤区间是负期望）；
4. 删除 RSI 信号（回测反向，AUC 0.30）；
5. 每半年重跑本目录脚本，若 OOS AUC 稳定超过 0.60 再考虑建模。

## 7. 复现

    python model/train.py     # HMM + 状态内 LR，输出逐折 AUC
    python model/compare.py   # 规则 / 单特征 / LR 横向对比
    python model/horizon.py   # 20/60/120/250 日敏感性
    python model/table.py     # 经验频率表
